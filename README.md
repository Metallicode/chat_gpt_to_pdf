# AI-to-PDF Exporter 🚀

A lightweight, private, and fast way to convert AI chat outputs (from Gemini, ChatGPT, etc.) into professionally styled PDF documents. This tool preserves **Markdown formatting**, **Syntax Highlighting** for code blocks, and **Nested Lists**.

## ✨ Features

* **Zero Server/Back-end:** Everything runs in your browser. Your data never leaves your computer.
* **Markdown Support:** Handles headers, bold text, tables, and blockquotes.
* **Code Highlighting:** Automatically formats code panels (e.g., Python, Bash, JS) using the GitHub Dark theme.
* **Clean Layout:** Optimized for A4 paper with intelligent page breaks.

## 🚀 How to Use

1. **Paste** your copied AI response into the text area.
2. **Name** your file in the filename box.
3. **Click** "Generate Styled PDF."

## 🛠️ Local Setup

If you want to run this locally:

1. Download `index.html`.
2. Open it in any web browser.
